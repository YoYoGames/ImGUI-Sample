# ImGUI API

Minimal discoverability index for the GMRT **ImGUI** compatibility module. Lists signatures with short descriptions and per-argument notes. Please note that everything here is experimental and may change in future!

This module wraps [Dear ImGui](https://github.com/ocornut/imgui) as a single global class, `ImGui`, whose members are all **static** — call them directly, e.g. `ImGui.Begin("Window")`. Signatures below are taken from `ImGUI.gmidl`.

## Conventions

- Signatures use type annotations after a colon: `name(param : type) : returnType`.
- A trailing `?` marks an optional parameter; `= value` shows its default.
- Each function lists its arguments as indented bullets, each tagged with its expected type in the form `` `name` *(type)* — description``. A `returns —` bullet is shown where the IDL documents the return value (the return type also appears at the end of the signature).
- GameMaker types are used throughout: `real`, `int32`, `int64`, `uint32`, `bool`, `string`, `array`, `object` (a struct), `pointer`, `sprite_asset`, and `any`.
- Many `flags` parameters expect an ImGui bitmask (e.g. `ImGuiWindowFlags`, `ImGuiTableFlags`). GML definitions for the enumerations are at the [end of this document](#enums) 
- Several widgets take a `state : object` struct so that ImGui can read/write UI state back to your code (e.g. `{ open, visible }` or `{ selected, visible }`).
- Functions come in both **British** (`Colour`) and **American** (`Color`) spellings where relevant; the two forms are aliases that bind to the same native implementation.


## ImGui

The single global static class exposed by this module. Invoke functions using `ImGui.FunctionName()` 

### Window Functions

- `Begin(name : string, state? : object, flags? : int64 = 0) : bool` - Push a window onto the stack and start appending to it.
  - `name` *(string)* — unique window identifier; text after `##` is ignored and used only to differentiate windows with identical display names.
  - `state?` *(object)* — state struct (or undefined): `open` true if window is open, `visible` true if contents are visible.
  - `flags?` *(int64)* — `ImGuiWindowFlags` combination controlling behavior (NoMove, NoResize, NoCollapse, etc.).
  - returns — true if the window is open and active (important for subsequent frame drawing).
- `End()` - Pop the current window from the stack.
- `BeginChild(name : string, width : real, height : real, flagsChild? : int64 = 0, flagsWindow? : int64 = 0) : bool` - Push a child window and start appending to it.
  - `name` *(string)* — unique identifier for the child window; allows multiple children with the same display name when suffixed with `##`.
  - `width` *(real)* — desired width in pixels; use 0 for auto width based on parent content region.
  - `height` *(real)* — desired height in pixels; use 0 for auto height based on parent content region.
  - `flagsChild?` *(int64)* — `ImGuiChildFlags` controlling child-specific behavior (Border, AutoResizeY, ResizeX, ResizeY, etc.).
  - `flagsWindow?` *(int64)* — `ImGuiWindowFlags` controlling window behavior inherited from the parent window.
  - returns — true if the child window is active this frame (allows conditional drawing of child contents).
- `EndChild()` - Pop a child window from the stack.
- `IsWindowAppearing() : bool` - Returns true if the window is appearing this frame.
- `IsWindowCollapsed() : bool` - Returns true if the window is collapsed.
- `IsWindowFocused(flags? : int64 = 0) : bool` - Returns true if the window has keyboard focus.
  - `flags?` *(int64)* — `ImGuiFocusedFlags` controlling focus scope (RootWindow, ChildWindows, etc.).
  - returns — true if the window has keyboard input focus.
- `IsWindowHovered(flags? : int64 = 0) : bool` - Returns true if the mouse is hovering the window.
  - `flags?` *(int64)* — `ImGuiHoveredFlags` controlling hover scope (ChildWindows, RootWindow, AllowWhenBlockedByPopup, etc.).
  - returns — true if the mouse cursor is over the window content area.
- `GetWindowDpiScale() : real` - Returns the DPI scale of the current window.
- `GetWindowX() : real` - Returns the X position of the current window.
- `GetWindowY() : real` - Returns the Y position of the current window.
- `GetWindowWidth() : real` - Returns the width of the current window.
- `GetWindowHeight() : real` - Returns the height of the current window.
- `GetWindowViewport() : pointer` - Returns the viewport of the current window.
- `SetWindowFontScale(_scale : real)` - Set the font scale of the current window.
  - `_scale` *(real)* — font size multiplier; 1.0 is normal size, 2.0 doubles the font size.
- `SetNextWindowViewport(_id : int32)` - Set the viewport of the next window.
  - `_id` *(int32)* — target viewport ID; determines which display/monitor the window renders to in multi-viewport setups.
- `SetNextWindowPos(_x : real, _y : real, _cond? : int32 = 0, _pivotX? : real = 0, _pivotY? : real = 0)` - Set the position of the next window.
  - `_x` *(real)* — target x position in screen pixels.
  - `_y` *(real)* — target y position in screen pixels.
  - `_cond?` *(int32)* — `ImGuiCond` flag (Always, Once, FirstUseEver, etc.) controlling when position is applied.
  - `_pivotX?` *(real)* — horizontal pivot point (0-1); 0=left edge, 0.5=center, 1=right edge.
  - `_pivotY?` *(real)* — vertical pivot point (0-1); 0=top edge, 0.5=center, 1=bottom edge.
- `SetNextWindowSize(_w : real, _h : real, _cond? : int32 = 0)` - Set the size of the next window.
  - `_w` *(real)* — desired window width in pixels; use 0 to let ImGui calculate based on content.
  - `_h` *(real)* — desired window height in pixels; use 0 to let ImGui calculate based on content.
  - `_cond?` *(int32)* — `ImGuiCond` flag controlling when size is applied.
- `SetNextWindowSizeConstraints(_minWidth : real, _minHeight : real, _maxWidth : real, _maxHeight : real)` - Set the size constraints of the next window.
  - `_minWidth` *(real)* — minimum allowed window width in pixels; 0 disables the minimum constraint.
  - `_minHeight` *(real)* — minimum allowed window height in pixels; 0 disables the minimum constraint.
  - `_maxWidth` *(real)* — maximum allowed window width in pixels; -1 or a very large value disables the maximum constraint.
  - `_maxHeight` *(real)* — maximum allowed window height in pixels; -1 or a very large value disables the maximum constraint.
- `SetNextWindowContentSize(_w : real, _h : real)` - Set the content size of the next window.
  - `_w` *(real)* — desired content width in pixels; affects scrollbar display and minimum window size.
  - `_h` *(real)* — desired content height in pixels; affects scrollbar display and minimum window size.
- `SetNextWindowCollapsed(_collapsed : bool, _cond? : int32 = 0)` - Set the collapsed state of the next window.
  - `_collapsed` *(bool)* — true to collapse the window to the title bar only; false to expand.
  - `_cond?` *(int32)* — `ImGuiCond` flag controlling when the state is applied.
- `SetNextWindowFocus()` - Focus the next window.
- `SetNextWindowScroll(_scrollX : real, _scrollY : real)` - Set the scroll of the next window.
  - `_scrollX` *(real)* — target horizontal scroll offset in pixels from the left.
  - `_scrollY` *(real)* — target vertical scroll offset in pixels from the top.
- `SetNextWindowBgAlpha(_alpha : real)` - Set the background alpha of the next window.
  - `_alpha` *(real)* — opacity from 0 (fully transparent) to 1 (fully opaque); applied to the window background.
- `GetScrollX() : real` - Returns the horizontal scroll of the current window.
- `GetScrollY() : real` - Returns the vertical scroll of the current window.
- `SetScrollX(_x : real)` - Set the horizontal scroll of the current window.
  - `_x` *(real)* — target horizontal scroll offset in pixels from the left edge.
- `SetScrollY(_y : real)` - Set the vertical scroll of the current window.
  - `_y` *(real)* — target vertical scroll offset in pixels from the top edge.
- `GetScrollMaxX() : real` - Returns the maximum horizontal scroll of the current window.
- `GetScrollMaxY() : real` - Returns the maximum vertical scroll of the current window.
- `SetScrollHereX(_x : real)` - Center the horizontal scroll on the current item.
  - `_x` *(real)* — center ratio (0-1); 0.0 aligns item to left, 0.5 to center, 1.0 to right.
- `SetScrollHereY(_y : real)` - Center the vertical scroll on the current item.
  - `_y` *(real)* — center ratio (0-1); 0.0 aligns item to top, 0.5 to center, 1.0 to bottom.
- `SetScrollFromPosX(_x : real, _xRatio? : real = 0.5)` - Scroll to a horizontal position with an alignment ratio.
  - `_x` *(real)* — target horizontal position in pixels to scroll to.
  - `_xRatio?` *(real)* — alignment ratio (0-1); 0.0 aligns to the left edge, 0.5 to center, 1.0 to the right edge.
- `SetScrollFromPosY(_y : real, _yRatio? : real = 0.5)` - Scroll to a vertical position with an alignment ratio.
  - `_y` *(real)* — target vertical position in pixels to scroll to.
  - `_yRatio?` *(real)* — alignment ratio (0-1); 0.0 aligns to the top edge, 0.5 to center, 1.0 to the bottom edge.
- `SetWindowPos(_name : string, _xPos : real, _yPos : real, _cond? : int32 = 0)` - Set the position of a named window.
  - `_name` *(string)* — target window name (empty string = current window); supports `##` suffix for disambiguation.
  - `_xPos` *(real)* — target x position in screen pixels.
  - `_yPos` *(real)* — target y position in screen pixels.
  - `_cond?` *(int32)* — `ImGuiCond` flag controlling when position is applied.
- `SetWindowSize(_name : string, _width : real, _height : real, _cond? : int32 = 0)` - Set the size of a named window.
  - `_name` *(string)* — target window name (empty string = current window); supports `##` suffix for disambiguation.
  - `_width` *(real)* — desired window width in pixels.
  - `_height` *(real)* — desired window height in pixels.
  - `_cond?` *(int32)* — `ImGuiCond` flag controlling when size is applied.
- `SetWindowCollapsed(_name : string, _collapsed : bool, _cond? : int32 = 0)` - Set the collapsed state of a named window.
  - `_name` *(string)* — target window name (empty string = current window); supports `##` suffix for disambiguation.
  - `_collapsed` *(bool)* — true to collapse the window to the title bar only; false to expand and show contents.
  - `_cond?` *(int32)* — `ImGuiCond` flag controlling when the state is applied.
- `SetWindowFocus(_name : string)` - Focus a named window.
  - `_name` *(string)* — target window name (empty string = current window); supports `##` suffix for disambiguation.

### API Functions

- `CreateContext() : pointer` - Create a new ImGui context.
- `DestroyContext(_ctx : pointer)` - Destroy an ImGui context.
  - `_ctx` *(pointer)* — context pointer to destroy; if null, destroys the current context.
- `GetCurrentContext() : pointer` - Get the current ImGui context.
- `SetCurrentContext(_ctx : pointer)` - Make a context current.
  - `_ctx` *(pointer)* — context pointer to make current; affects subsequent ImGui calls.
- `ShowDemoWindow(_open? : bool = true) : bool` - Show the built-in demo window.
  - `_open?` *(bool)* — initial open state; passes the current state back for a persistent window toggle.
- `ShowMetricsWindow(_open? : bool = true) : bool` - Show the metrics/debug window.
  - `_open?` *(bool)* — initial open state; passes the current state back for a persistent window toggle.
- `ShowDebugLogWindow(_open? : bool = true) : bool` - Show the debug log window.
  - `_open?` *(bool)* — initial open state; passes the current state back for a persistent window toggle.
- `ShowStackToolWindow(_open? : bool = true) : bool` - Show the stack tool window.
  - `_open?` *(bool)* — initial open state; passes the current state back for a persistent window toggle.
- `ShowAboutWindow(_open? : bool = true) : bool` - Show the about window.
  - `_open?` *(bool)* — initial open state; passes the current state back for a persistent window toggle.
- `ShowStyleEditor()` - Show the style editor.
- `ShowStyleSelector(name : string)` - Show a style selector combo.
  - `name` *(string)* — label for the selector widget; multiple selectors can coexist with different labels.
- `ShowFontSelector(name : string)` - Show a font selector combo.
  - `name` *(string)* — label for the selector widget; multiple selectors can coexist with different labels.
- `ShowUserGuide()` - Show the user guide help block.
- `GetVersion() : string` - Return the ImGui version string.
- `PushID(_id)` - Push an ID onto the ID stack.
  - `_id` *(any)* — ID value to push (string or integer); used for widget identification and state tracking.
- `PopID()` - Pop an ID from the ID stack.
- `GetID(_id : string) : int32` - Hash a string into a unique ID.
  - `_id` *(string)* — string to hash into a unique ID; useful for generating stable IDs for widgets.
- `PushItemFlag(_itemFlag : int64, _enabled : bool)` - Push an item flag for subsequent items.
  - `_itemFlag` *(int64)* — `ImGuiItemFlags` value to apply to subsequent items (NoTabStop, ButtonRepeat, etc.).
  - `_enabled` *(bool)* — true to apply the flag, false to disable this flag push/pop block.
- `PopItemFlag()` - Pop an item flag.
- `BeginDisabled(_enabled : bool)` - Begin a disabled block.
  - `_enabled` *(bool)* — true to disable all interactive widgets, false to keep them enabled.
- `EndDisabled()` - End a disabled block.
- `IsItemHovered(_itemFlag? : int64 = 0) : bool` - Returns true if the last item is hovered.
  - `_itemFlag?` *(int64)* — `ImGuiHoveredFlags` controlling hover scope and behavior (ChildWindows, RootWindow, etc.).
- `IsItemActive() : bool` - Returns true if the last item is active.
- `IsItemFocused() : bool` - Returns true if the last item is focused.
- `IsItemClicked() : bool` - Returns true if the last item is clicked.
- `IsItemVisible() : bool` - Returns true if the last item is visible.
- `IsItemEdited() : bool` - Returns true if the last item was edited.
- `IsItemActivated() : bool` - Returns true if the last item was activated.
- `IsItemDeactivated() : bool` - Returns true if the last item was deactivated.
- `IsItemDeactivatedAfterEdit() : bool` - Returns true if the last item was deactivated after an edit.
- `IsItemToggledOpen() : bool` - Returns true if the last item was toggled open.
- `IsAnyItemHovered() : bool` - Returns true if any item is hovered.
- `IsAnyItemActive() : bool` - Returns true if any item is active.
- `IsAnyItemFocused() : bool` - Returns true if any item is focused.
- `GetItemID() : uint32` - Get the ID of the last item.
- `GetItemRectMinX() : real` - Get the minimum X of the last item's rect.
- `GetItemRectMinY() : real` - Get the minimum Y of the last item's rect.
- `GetItemRectMaxX() : real` - Get the maximum X of the last item's rect.
- `GetItemRectMaxY() : real` - Get the maximum Y of the last item's rect.
- `GetItemRectSizeWidth() : real` - Get the width of the last item's rect.
- `GetItemRectSizeHeight() : real` - Get the height of the last item's rect.
- `SetNextItemAllowOverlap()` - Allow the next item to be overlapped by later items.
- `BeginItemTooltip() : bool` - Begin a tooltip for the last item (only if hovered).
- `SetItemTooltip(_tip : string)` - Set a tooltip for the last item.
  - `_tip` *(string)* — tooltip text to display when hovering the item.
- `IsRectVisible(_x1 : real, _y1 : real, _x2 : real, _y2 : real) : bool` - Returns true if the given rect is visible/not clipped.
  - `_x1` *(real)* — top-left X position of the rect in screen coordinates.
  - `_y1` *(real)* — top-left Y position of the rect in screen coordinates.
  - `_x2` *(real)* — bottom-right X position of the rect in screen coordinates.
  - `_y2` *(real)* — bottom-right Y position of the rect in screen coordinates.
- `GetTime() : real` - Get the current ImGui time.
- `GetFrameCount() : int32` - Get the frame count.
- `CalcTextWidth(_text : string, _hideTextAfterDoubleDash? : bool = false, _wrapWidth? : real = -1) : real` - Calculate the pixel width of text.
  - `_text` *(string)* — string to measure in pixels.
  - `_hideTextAfterDoubleDash?` *(bool)* — when true, text after the `##` separator is ignored in measurement.
  - `_wrapWidth?` *(real)* — if positive, measures wrapped text; use -1 for no wrapping.
- `CalcTextHeight(_text : string, _hideTextAfterDoubleDash? : bool = false, _wrapWidth? : real = -1) : real` - Calculate the pixel height of text.
  - `_text` *(string)* — string to measure in pixels.
  - `_hideTextAfterDoubleDash?` *(bool)* — when true, text after the `##` separator is ignored in measurement.
  - `_wrapWidth?` *(real)* — if positive, measures wrapped text; use -1 for no wrapping.
- `PushAllowKeyboardFocus(_allowKeyboardFocus : bool)` - Push whether widgets may take keyboard focus.
  - `_allowKeyboardFocus` *(bool)* — true to allow keyboard focus on widgets; false to prevent keyboard interaction.
- `PopAllowKeyboardFocus()` - Pop the keyboard-focus allowance.
- `SetKeyboardFocusHere(_offset? : int32 = 0)` - Set keyboard focus to the current (or offset) item.
  - `_offset?` *(int32)* — widget offset; 0 focuses the current item, positive offsets focus later items.
- `PushButtonRepeat(_repeat : bool)` - Push whether held buttons repeat.
  - `_repeat` *(bool)* — true to make buttons repeat when held; false for normal one-press behavior.
- `PopButtonRepeat()` - Pop the button-repeat setting.
- `SetItemDefaultFocus()` - Make the last item the default-focused item.
- `ConfligFlagsGet() : int32` - Get the config flags. *(Note: spelled `ConfligFlagsGet` in the IDL.)*
- `IniFilename(_filename? : string) : string` - Get or set the ini filename.
  - `_filename?` *(string)* — when provided, sets the ini file path; when empty, returns the current path.
- `WantSaveIniSettings(_enable? : bool) : bool` - Get/set whether ini settings should be saved.
  - `_enable?` *(bool)* — when true, enables ini saving; when false, disables it.
- `LoadIniSettingsFromDisk(_filename? : string)` - Load ini settings from disk.
  - `_filename?` *(string)* — path to the ini file; if empty, uses the filename from `IniFilename()`.
- `LoadIniSettingsFromMemory(_ini? : string)` - Load ini settings from a string.
  - `_ini?` *(string)* — ini-format settings string to load (typically from `SaveIniSettingsToMemory`).
- `SaveIniSettingsToDisk(_ini? : string)` - Save ini settings to disk.
  - `_ini?` *(string)* — filename to save to; if empty, uses the filename from `IniFilename()`.
- `SaveIniSettingsToMemory() : string` - Save ini settings to a string.
- `ClearIniSettings()` - Clear ini settings.
- `ConfigFlagsSet(_flags : uint32)` - Set config flags.
  - `_flags` *(uint32)* — `ImGuiConfigFlags` bitmask to enable (NavEnableKeyboard, NavEnableGamepad, etc.).
- `ConfigFlagToggle(_flags : uint32) : uint32` - Toggle config flags.
  - `_flags` *(uint32)* — `ImGuiConfigFlags` bitmask to toggle on/off.
- `GetMainViewport() : pointer` - Get the main viewport.
- `GetViewportID(_viewport : pointer) : uint32` - Get the ID of a viewport.
  - `_viewport` *(pointer)* — viewport pointer to retrieve the ID from.
- `LogText(_text : string)` - Append text to the current log.
  - `_text` *(string)* — text string to append to the current log output.
- `LogToClipboard(_autoExpandDepth? : int32 = -1)` - Start logging to the clipboard.
  - `_autoExpandDepth?` *(int32)* — tree expansion depth (-1 for no auto-expand).
- `LogToTTY(_autoExpandDepth? : int32 = -1)` - Start logging to the TTY.
  - `_autoExpandDepth?` *(int32)* — tree expansion depth (-1 for no auto-expand).
- `LogToFile(_autoExpandDepth? : int32 = -1, filename? : string)` - Start logging to a file.
  - `_autoExpandDepth?` *(int32)* — tree expansion depth (-1 for no auto-expand).
  - `filename?` *(string)* — output file path to write logs to.
- `LogFinish()` - Finish logging.
- `LogButtons()` - Draw the built-in logging buttons.
- `SetNextFrameWantCaptureKeyboard(_enable : bool)` - Request keyboard capture for the next frame.
  - `_enable` *(bool)* — true to prevent other input handlers from receiving keyboard input next frame.
- `SetNextFrameWantCaptureMouse(_enable : bool)` - Request mouse capture for the next frame.
  - `_enable` *(bool)* — true to prevent other input handlers from receiving mouse input next frame.
- `WantKeyboardCapture(_enable? : bool) : bool` - Get/set whether ImGui wants keyboard capture.
  - `_enable?` *(bool)* — when provided, sets the keyboard capture state; when empty, returns the current state.
- `WantMouseCapture(_enable? : bool) : bool` - Get/set whether ImGui wants mouse capture.
  - `_enable?` *(bool)* — when provided, sets the mouse capture state; when empty, returns the current state.
- `WantTextInput(_enable? : bool) : bool` - Get/set whether ImGui wants text input.
  - `_enable?` *(bool)* — when provided, sets the text input state; when empty, returns the current state.
- `WantMouseUnlessPopupClose(_enable? : bool) : bool` - Get/set whether ImGui wants the mouse unless a popup is closing.
  - `_enable?` *(bool)* — when provided, sets the mouse capture state; when empty, returns the current state.

### Widget Functions

- `Button(label : string, width? : real = 0, height? : real = 0) : bool` - Create a button; returns true when clicked.
  - `label` *(string)* — button display text; can contain `##` for a hidden ID suffix.
  - `width?` *(real)* — button width in pixels; 0 = auto width based on content.
  - `height?` *(real)* — button height in pixels; 0 = auto height based on default.
- `SmallButton(label : string) : bool` - Create a compact button.
  - `label` *(string)* — button display text; compact version of a regular button.
- `InvisibleButton(label : string, width? : real = 0, height? : real = 0, flags? : uint32 = 0) : bool` - Create an invisible/hit-test button.
  - `label` *(string)* — button identifier (not displayed); use `##` suffix to disambiguate.
  - `width?` *(real)* — hit-test area width in pixels.
  - `height?` *(real)* — hit-test area height in pixels.
  - `flags?` *(uint32)* — `ImGuiButtonFlags` controlling behavior (Repeat, PressedOnClick, etc.).
- `ArrowButton(label : string, flags? : uint32 = 0) : bool` - Create a directional arrow button.
  - `label` *(string)* — button identifier (not displayed); use `##` suffix to disambiguate.
  - `flags?` *(uint32)* — `ImGuiDir` direction flag (Up, Down, Left, Right).
- `Checkbox(label : string, checked : bool) : bool` - Create a checkbox; returns the (possibly toggled) state.
  - `label` *(string)* — checkbox display text; supports `##` suffix for a hidden ID.
  - `checked` *(bool)* — checked state; the value is modified when the user clicks.
- `CheckboxFlags(label : string, flags : uint32, flagsValue : uint32) : uint32` - Create a checkbox that toggles a bit within a flags value.
  - `label` *(string)* — checkbox display text; supports `##` suffix for a hidden ID.
  - `flags` *(uint32)* — bitmask containing all flags.
  - `flagsValue` *(uint32)* — specific flag bit to toggle when clicked.
- `RadioButton(label : string, checked : bool) : bool` - Create a radio button.
  - `label` *(string)* — radio button display text; supports `##` suffix for a hidden ID.
  - `checked` *(bool)* — true if this button is selected.
- `ProgressBar(frac : real, width : real, height : real, label? : string)` - Draw a progress bar.
  - `frac` *(real)* — progress completion from 0.0 to 1.0.
  - `width` *(real)* — bar width in pixels; -1 for full available width.
  - `height` *(real)* — bar height in pixels; -1 for default height.
  - `label?` *(string)* — optional text overlay on the bar.
- `Bullet()` - Draw a bullet point.
- `TextLink(label : string)` - Draw a clickable text link.
  - `label` *(string)* — link text displayed to the user.
- `TextLinkOpenURL(label : string, url : string)` - Draw a text link that opens a URL when clicked.
  - `label` *(string)* — link text displayed to the user.
  - `url` *(string)* — URL to open when clicked (http://, https://, mailto:, etc.).
- `Image(sprite : sprite_asset, subImage : int32, colour? : int32 = 0xffffff, alpha? : real = 1.0, width? : real = 0, height? : real = 0, uvs? : array)` - Draw a sprite image.
  - `sprite` *(sprite_asset)* — sprite asset to display.
  - `subImage` *(int32)* — frame index within the sprite; 0 for the first frame.
  - `colour?` *(int32)* — color tint (RGB); white (0xffffff) for no tint.
  - `alpha?` *(real)* — opacity from 0 (transparent) to 1 (opaque).
  - `width?` *(real)* — display width in pixels; 0 = sprite width.
  - `height?` *(real)* — display height in pixels; 0 = sprite height.
  - `uvs?` *(array)* — custom UV coordinates [u0,v0,u1,v1]; null for the full sprite.
- `ImageButton(strID : string, sprite : sprite_asset, subImage : int32, colour? : int32 = 0xffffff, alpha? : real = 1.0, colourBG? : int32 = 0x000000, alphaBG? : real = 1.0, width? : real = 0, height? : real = 0, uvs? : array) : bool` - Draw a clickable sprite image button.
  - `strID` *(string)* — unique button identifier; use `##` suffix to hide display text.
  - `sprite` *(sprite_asset)* — sprite asset to display.
  - `subImage` *(int32)* — frame index within the sprite; 0 for the first frame.
  - `colour?` *(int32)* — image color tint (RGB); white (0xffffff) for no tint.
  - `alpha?` *(real)* — image opacity from 0 (transparent) to 1 (opaque).
  - `colourBG?` *(int32)* — background color (RGB); 0 for transparent.
  - `alphaBG?` *(real)* — background opacity from 0 (transparent) to 1 (opaque).
  - `width?` *(real)* — display width in pixels; 0 = sprite width.
  - `height?` *(real)* — display height in pixels; 0 = sprite height.
  - `uvs?` *(array)* — custom UV coordinates [u0,v0,u1,v1]; null for the full sprite.
- `Surface(surface : int32, colour? : int32 = 0xffffff, alpha? : real = 1.0, width? : real = 0, height? : real = 0, uvs? : array)` - Draw a GameMaker surface as an image.
  - `surface` *(int32)* — surface ID to display (must be valid and exist).
  - `colour?` *(int32)* — color tint (RGB); white (0xffffff) for no tint.
  - `alpha?` *(real)* — opacity from 0 (transparent) to 1 (opaque).
  - `width?` *(real)* — display width in pixels; 0 = surface width.
  - `height?` *(real)* — display height in pixels; 0 = surface height.
  - `uvs?` *(array)* — custom UV coordinates [u0,v0,u1,v1]; null for the full surface.

### Tree Functions

- `TreeNode(label : string) : bool` - Create a tree node; returns true when open.
  - `label` *(string)* — tree node display text; supports `##` suffix for a hidden ID.
